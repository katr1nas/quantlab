The main goal of this project is to create an environment for testing trading hypotheses using statistics and data. First, I created a data template so users can manually input their trading data. In the src directory, there are several modules, each responsible for a specific function. As my first statistical tool, I chose Monte Carlo simulation to explore possible outcomes based on the historical distribution of trades. In the metrics module, I implemented functions for expectancy, Sharpe ratio, profit factor, maximum drawdown, and other metrics. These metrics allow users to identify the strengths and weaknesses of their strategies.
