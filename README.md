The main goal of this project create a environment for testing trading hypothesis through statistics and data. Firstly, I made a data template for beginning, so user can put his data manually.
In ./src we can find a lot of files and each of them execute their own function. Secondly, I choose first statistics a Monte Carlo which test your strategy on real market circumantainces and environment. In metrics I made function
such as, expectancy, sharpe, profit factor, max drawdown and so on, so user can observe strong and weak parts of his strategies.
